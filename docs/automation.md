# 每日自动巡店

先完成技能安装、自己的表格配置、Google Sheets连接和浏览器可用性检查。Skill承载规则；应用的自动化功能负责触发；二者分别配置。

## 创建任务的示例请求

```text
每天北京时间09:00（Asia/Shanghai，沙特04:00），使用 $saudi-store-audit 巡检我已配置的Noon与Amazon工作表并直接更新原表。

运行前读取已安装的Skill及本地表格配置，按实际运行日创建或复用当天唯一日期列组；不复制昨日价格，不覆盖历史，同日重试不重复建列。

逐链接核实同一商品及变体。Amazon先确认配送地区为Riyadh。无划线价则MSRP留空；确认缺货则在Price／Offer Price填OOS，Note仅写sold by实际非平台卖家。Noon页面显示This product is not available且Status=EOL时，当天三项留空；同日重跑只清理当天巡店自动内容，人工冲突保留并报告。

分批回写并读回复核，报告日期组范围、完成数量、普通OOS、EOL跳过、实际卖家、失败行、冲突及更新数量。缺少连接、网页无法核实或写入受阻时报告实际进度，不伪称成功。

漏跑只记录实际运行日期，不补造历史实时价。上一轮未结束时避免并发建组。定时触发只执行巡店，不重复创建定时器。
```

创建前检查是否已有同目标任务；已有则更新。调度时间和日期标签时区分别记录，避免跨时区后写错日期。实际创建时必须由用户指定或确认时刻，并提供可读取的本地配置或明确表格URL。

安装本仓库不会转移其他电脑的Google权限、浏览器登录或定时任务。定时巡店涉及本机技能和浏览器时，需要电脑和应用保持运行。

## 每次运行的报告

- 实际执行时间、日期时区、两表新增或复用的A1范围。
- 产品总数、整行页面核验完成数、部分核验数、EOL跳过数、普通OOS数。
- 实际写入及读回复核成功数、EOL清理格数、非平台卖家。
- 失败行、未核实字段、人工/公式冲突及需要处理的连接问题。

EOL跳过不算访问失败；结构创建成功不等于完成查价；部分价格核实不等于整行完成。详细证据另存运行记录，Note保持只记录实际非平台卖家。

新建或复用当天组时，Price／Offer Price正文均统一右对齐，OOS仍以文本保存。缺链接行不写Note，已确认由巡店生成的当天旧Note精确清空；价格/Buy Box只保留为未核实，人工/公式内容保留并报告冲突。每轮结束对有内容的当天Note按完整文字自动列宽、单行显示；全空Note列不缩窄，不改变字号或行高。仅允许这些当天格式变化，历史组和其他布局保持不变。
